# markion-site

GitHub Pages for the Markion Chrome extension.

- `help/` is the user guide (source: `docs/store/help.html` in the Markion repo, images from `docs/store/shots/en/guide/` via `npm run store:shots -- --lang en --guide`).
- `privacy/` is the privacy policy (source: `docs/store/privacy.html` in the Markion repo).
- `support/` redirects to the donation page. The extension links only to this URL, so the payment target can change without a store review.
